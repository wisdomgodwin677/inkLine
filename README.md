# inkLine

Write it down. Tick it off.

A notebook-style to-do app built with plain HTML, CSS, and JavaScript.

**Live demo:** https://wisdomgodwin677.github.io/inkline/

## Features
- Add, edit, and delete tasks
- Due dates, sorted soonest first, with overdue dates in red
- Filter by All, Active, or Completed
- Clear all completed tasks
- Light and dark theme
- Tasks save in your browser (localStorage)

## Run it locally
Open `index.html` in your browser, or use the Live Server extension in VS Code.

## Built with
HTML, CSS, JavaScript. No frameworks.
